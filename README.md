# Vector Terminal

Vector Terminal is a web-based terminal application built with React, TypeScript, and Vite. It offers a modern, efficient interface for interacting with a server or local environment.

## Features

- **Modern UI**: Built with React, styled with a component library.
- **Efficient Rendering**: Uses Vite for fast builds.
- **TypeScript**: Type-safe and maintainable.
- **Customizable**: Easily extendable commands, themes, and plugins.

## Tech

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [ESLint](https://eslint.org/)
- [Vitest](https://vitest.dev/)
